# Fork note: Diary Weight Trend Widget

This fork adds a Diary homepage **Weight** trend card alongside the existing **Water Intake** tile. Upstream `dashboardLayout.ts` is untouched; default placement for `weight` is injected in `DiaryWidgetGrid`.

## What it shows

- Current body weight (from check-in measurements, in the user’s preferred unit)
- The last 5 weight check-ins
- Green / red / neutral coloring from Settings **Goal Mode** (cut / bulk / maintain / …), refined by onboarding `target_weight` when present

## Coolify / Docker

No new Compose environment variables.

1. Deploy from this fork’s **`deploy`** branch (or equivalent) using your fork images — not upstream `codewithcj/*` if you need this widget.
2. Users log weight via **Check-In** as usual.
3. Goal direction comes from **Settings → Calculation** (Goal Mode). Target weight is set during onboarding (`onboarding_data.target_weight`).
4. In Diary **Layout** edit mode, users can move, resize, or hide either the water or weight widget.
